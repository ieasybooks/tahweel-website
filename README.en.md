This repository contains the official website for the **Tahweel** project. The site is a static page (HTML, CSS, JavaScript) hosted on Netlify that showcases features and provides download links for the latest desktop application releases directly from GitHub.

## Related Projects

- 🐍 [ieasybooks/tahweel](https://github.com/ieasybooks/tahweel) — The original Python implementation
- 💎 [ieasybooks/tahweel.rb](https://github.com/ieasybooks/tahweel.rb) — Ruby gem and command-line interface
- 🖥️ [ieasybooks/tahweel-tauri](https://github.com/ieasybooks/tahweel-tauri) — Desktop application built with Tauri
